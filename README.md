# AnimeDramaStudio

Studio animasi anime sederhana yang berjalan langsung di browser, tanpa API AI.

## Fitur prototipe
- Unggah gambar karakter PNG/JPG/WebP
- Unggah latar belakang
- Gerakan 2D sederhana
- Dialog menggunakan Text-to-Speech browser
- Lapisan mulut animasi dengan posisi dan ukuran yang dapat disesuaikan
- Simpan pratinjau panggung sebagai PNG
- Pengaturan dialog dan gerakan disimpan lokal di browser

## Jalankan
Buka `index.html` di browser, atau publikasikan repository ini melalui GitHub Pages.

### Aktifkan GitHub Pages
1. Buka **Settings** repository.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
5. Tunggu proses publikasi selesai. URL biasanya berbentuk `https://thatosenyum95-ship-it.github.io/AnimeDramaStudio/`.

## Batasan prototipe
Satu gambar karakter utuh tidak memiliki rig tubuh atau data bentuk mulut. Gerakan dan mulut pada prototipe ini berupa overlay 2D sederhana yang perlu disesuaikan secara manual. Dukungan suara bergantung pada browser dan suara TTS yang tersedia di perangkat. Ekspor video MP4 belum tersedia pada versi awal.
